# D1.1 — Skill Ontology Sourcing Standard & SK13 Evidence Matrix

## Overview

Issue #482 (D1.1) establishes the canonical **Skill Ontology Sourcing Standard**. Every subskill in the FLN platform must be justified and traceable to primary government and research benchmarks rather than arbitrary authoring.

---

## 1. The 7-Column Evidence Matrix Standard

Each subskill definition in the FLN ontology is grounded in seven named evidence columns:

| Field | Source / Description | Source Identifier / DB Key |
|---|---|---|
| **Learning Outcome** | NCERT *Learning Outcomes at Elementary Stage* (Class 1–5 Mathematics) | `learning_outcome` |
| **Competency** | NIPUN Bharat Lakshya (Grade 1–3 foundational numeracy targets) | `competency` |
| **Curriculum Expectation** | NCF-FS 2022 (Foundational: ages 3–8) / NCF-SE 2023 (Preparatory: Classes 3–5) | `curriculum_expectation` |
| **Instructional Evidence** | State/NCERT Textbooks & Teacher Handbooks (Pedagogical sequence) | `instructional_evidence` |
| **Assessment Evidence** | NAS / ASER / State Assessment Frameworks (Task types) | `assessment_evidence` |
| **Research Evidence** | Empirical learning-progression / cognitive-development literature | `research_evidence` |
| **Validation Status** | Expert review & empirical pilot validation status (`PROPOSED` / `VALIDATED`) | `validation_status` |
