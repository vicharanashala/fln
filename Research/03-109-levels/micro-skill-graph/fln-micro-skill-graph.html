The two red entries recurring through the graph

  • recognise the operator symbol — resolved 2026-09-15, no code added. Was flagged on 16 Levels. Checked both government documents directly: NCERT's Learning Outcomes at the Elementary Stage never lists symbol-recognition as its own outcome anywhere in the mainstream curriculum — the Class I addition outcome itself just writes "3+3=6" inline, with no separate "recognises +" step before it. The only place "operational symbols" is named at all is the special-needs appendix, as a noted difficulty for children with cognitive impairments, not a mainstream learning target. NIPUN Bharat's guidelines don't mention math symbols at all. Decision: follow the source — no standalone subskill; symbol reading stays implicit inside each operation's own subskill (SK13.03, SK15.01, etc.), so the 16 MISSING markers were removed rather than filled in.
  • face value (distinct from place value) — resolved 2026-09-15. Was on 22 Levels, everything touching place value (only meaningfully distinct at two digits and above, which is why it stayed invisible). Added as SK11.10 — Face value in skillProgressionMap.ts and every one of the 22 flagged Levels updated to reference it.
  • Also added 2026-09-15 (Pavani/Amritha review): SK08.09 Zero as "none" (L39), SK15.08 Factors and multiples (L89), SK17.06 Decimal notation, tenths & hundredths (L90) — plus four wrong-skill corrections (L55, L59, L65, L70) and a missing required edge (L61 → L50).
