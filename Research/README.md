# Research: how the FLN levels came to be

**Looking for the current list of levels and subskills?** Go straight to [03-109-levels/](./03-109-levels/README.md).

This folder is organised by **which version of the curriculum a document describes**. The curriculum has changed twice: 59 levels, then 93, now **109**. Older documents keep their old numbers on purpose, so each era has its own folder.

| Folder | Era | Use it for |
|---|---|---|
| [01-original-59-levels/](./01-original-59-levels/README.md) | The first curriculum, 59 levels | History, and the old worksheet engine (it is still being migrated away from) |
| [02-93-levels/](./02-93-levels/README.md) | The second curriculum, 93 levels | How the framework was built from research, and the crosswalks between numberings |
| [03-109-levels/](./03-109-levels/README.md) | **Current**, 109 levels | The level list, skills, subskills, Balvatika decisions, the skill graph |
| [04-background-research/](./04-background-research/README.md) | Not tied to a version | Policy, national data, child psychology, assessment theory, Knowledge Space Theory |

## Two rules for everything in this folder

- Nothing here is a standard on its own authority. If a claim matters, check the external source it rests on. See [04-background-research/fln_source_verification_2026-08-21.md](./04-background-research/fln_source_verification_2026-08-21.md).
- When a document here disagrees with the code or with `03-109-levels/`, the code and `03-109-levels/` are right.
