# Original 59 levels (legacy)

The first FLN curriculum had **59 levels**, from Preschool 1 to Class 4. It is kept here for history and because the old worksheet engine (`levels_main.html`) and the 59 to 109 migration still refer to it.

**Do not use these level numbers as current level numbers.** The current curriculum has 109 levels: see [../03-109-levels/](../03-109-levels/README.md).
